Veritas

Adversarial verification for AI-written and AI-modified code: mutation scoring, fuzzing, corpus replay, generated assertions, and a confidence score for every change.

The AI Verification Loop

Review
Map changed files to symbols, risks, and agent instructions.
Attack
Run tests, fuzzing, mutation probes, coverage, and replay manifests.
Close
Promote assertion candidates, corpus seeds, and regression scaffolds.

Install

cargo install veritas-cli --locked

# Until the crate release is available:
cargo install --git https://github.com/Jacobious52/veritas veritas-cli --locked

Use With An AI Agent

veritas review-ai
veritas verify --changed --profile ci
veritas score

# Promote useful findings into reviewed tests:
veritas promote-regression --index 0
